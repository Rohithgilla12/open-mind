# Desk (Pinboard) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]` tracking.

**Goal:** Pin items to a Desk board; pin/unpin from cards + detail; `/desk` screen shows pinned items newest-first. Spec: `docs/superpowers/specs/20260706-desk-design.md`.

**Architecture:** `items.pinned_at` column; `PATCH /items/{id}` gains `pinned bool`; `GET /desk`; web `/desk` page + pin toggle + live sidebar Desk nav. Reuses PATCH /items infra, Grid/ItemCard, feeds/lenses page patterns.

## Global Constraints

- `pinned_at timestamptz` null = not pinned. Additive migration (no generated-column rebuild). Partial index on pinned rows.
- Every query user-scoped (SetItemPinned/ListPinned/PATCH → 404 cross-tenant). PATCH accepts optional `userTags` and/or `pinned`; neither present → 400 (preserve existing behaviour). `Item`/`ItemDetail` gain `pinnedAt` (nullable). Generated code never hand-edited; errors `%w`; no banner comments. `go test -p 1 ./... && golangci-lint run ./...` + web `pnpm turbo run build lint --filter=web` green. Tokens-only web. Commit per task.
