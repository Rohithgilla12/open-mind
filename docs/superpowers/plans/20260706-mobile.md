# Openmind Mobile (Expo) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]` tracking.

**Goal:** A standalone Expo app in `apps/mobile` — token login, capture (URL/note), library list, and share-sheet capture. Spec: `docs/superpowers/specs/20260706-mobile-design.md`.

**Architecture:** Standalone Expo (SDK 52+, TS, expo-router), OWN package.json + lockfile, NOT in the pnpm workspace. Inlined theme tokens. expo-secure-store auth. expo-share-intent for the share sheet. Consumes the web `/api/*` Bearer routes.

## Global Constraints

- Standalone: `apps/mobile` is NOT added to `pnpm-workspace.yaml`; it has its own deps (install with npm or pnpm — pick what installs cleanly for Expo; document it). Inline the ~6 tokens + font names in `theme.ts` (do NOT import @openmind/ui). Hand-write the tiny API client (no @openmind/api-client import).
- Thin client: capture + display only; no enrichment logic. Token in expo-secure-store only, never logged. All API calls Bearer to `{instanceUrl}/api/*`.
- One new dep is expo-share-intent (justified: native share extension); otherwise standard Expo libs (expo-router, expo-secure-store, expo-web-browser, expo-font optional). No change to the Go/web/self-host core.
- Verification is partial by nature (see spec): tsc + `expo export --platform web` + web-preview screenshot for the UI; share-intent wired + documented, device-only. Commit per task. No server deploy.

### Task 2: Library + Capture screens

**Files:** `apps/mobile/app/(tabs)/index.tsx` (Library), `apps/mobile/app/(tabs)/capture.tsx` (Capture), shared card component `apps/mobile/components/ItemRow.tsx`

**Interfaces:** consumes `listItems`/`saveItem`. Library: FlatList of ItemRow (title-or-host + state caption + card-type), RefreshControl pull-to-refresh, tap → expo-web-browser openBrowserAsync(`{instanceUrl}/item/{id}`), empty + unconfigured states. Capture: TextInput (URL-vs-note auto-detect via `/^https?:\/\//i`) + Save button → saveItem → success feedback + clear; error states (401/0/other).

- [ ] Step 1: ItemRow + Library screen (list, pull-to-refresh, tap-to-open, empty/unconfigured). 
- [ ] Step 2: Capture screen (input, detect, save, feedback). Warm theme throughout.
