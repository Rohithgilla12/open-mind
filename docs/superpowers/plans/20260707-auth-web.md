# Auth Web (slice 2/3): Clerk + Devices & Keys + QR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The web app gains a **Devices & Keys** settings page (mint/revoke API keys; connect-a-device with a big short code + QR deep link) that works in token mode today, plus env-gated Clerk sign-in (`AUTH_MODE=clerk`) whose session JWT flows through the existing proxies to the API.

**Architecture:** New cookie-proxy routes for `/api-keys` + `/device-links` (existing `apiFetch` pattern). A `/settings/devices` page (client components; tokens-only styling) with a QR rendered by a tiny client-side generator. Clerk (`@clerk/nextjs`) is wrapped behind `NEXT_PUBLIC_AUTH_MODE`: token mode keeps today's login/middleware byte-identical; clerk mode swaps in `clerkMiddleware` + `<SignIn/>` and `apiFetch` attaches the Clerk session JWT instead of the om_token cookie. Ships dark again — token-mode compose e2e is the regression gate; clerk-mode runtime is verified at cloud cutover with the user's real keys.

**Tech Stack:** Next.js 15 (existing), `@clerk/nextjs` (new dep, the point of the slice), `qrcode` (new dep — client-side QR SVG/canvas, no network).

Spec: `docs/superpowers/specs/20260707-auth-design.md`. API contract (already live on `main`): `GET/POST /api-keys`, `DELETE /api-keys/{id}`, `POST /device-links {deviceHint?} → {code, expiresAt}`, `POST /device-links/claim` (public).

## Global Constraints

- **Ships dark:** with `NEXT_PUBLIC_AUTH_MODE` unset/`token`, web behaviour is byte-identical to today (om_token login, middleware redirect, apiFetch cookie→Bearer). All existing compose e2e must pass unchanged.
- Design tokens from `@openmind/ui` only; mono captions; match the app's warm-editorial rail/table styling (read neighbouring pages). No banner comments; strict TS; keys shown once and never logged/persisted client-side beyond display state.
- QR payload exactly: `openmind://link?code=<ABCD-EFGH>&url=<instance origin>` (instance origin = `window.location.origin`).
- `pnpm --filter web build` + `lint` gates; `pnpm exec`, never bare npx.
