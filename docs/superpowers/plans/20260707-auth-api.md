# Auth API (slice 1/3): keys, device links, middleware Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Go API gains per-user API keys, the QR/short-code device-connect flow, and a credential-resolving auth middleware (API key / Clerk JWT / legacy token) — shipping dark: with `AUTH_MODE` unset, today's behaviour is byte-identical.

**Architecture:** Migration 0011 adds `users.clerk_user_id/email`, `api_keys`, `device_links`. A new `internal/auth` package owns credential resolution: `omk_`-prefixed keys (SHA-256 hash lookup), Clerk session JWTs (RS256 via a JWKS cache; JIT user provisioning), or the legacy `OPENMIND_TOKEN` (token mode). The chi middleware sets the resolved user id in context — `userID(ctx)` and every handler stay unchanged. Contract gains `/api-keys` CRUD + `/device-links` mint/claim; claim is unauthenticated-by-design (the code is the credential) with its own strict rate bucket.

**Tech Stack:** Existing stack + `github.com/golang-jwt/jwt/v5` (new dep, justified: RS256/JWT verification is not DIY crypto). JWKS fetch/cache hand-rolled with stdlib HTTP.

Spec: `docs/superpowers/specs/20260707-auth-design.md`.

## Global Constraints

- **Ships dark:** `AUTH_MODE` unset/`token` ⇒ existing deployments (incl. production) behave identically: `OPENMIND_TOKEN` works, dev user auto-provisioned, `/healthz` open. Full existing test suite must stay green untouched except where middleware wiring changes require test-server construction updates.
- Keys/codes **hashed at rest** (SHA-256); the full key is returned exactly once; never logged. Uniform `404` for wrong/expired/used claim codes. No secrets in error strings.
- Contract workflow: `openapi.yaml` → regen (oapi-codegen v2.4.1 + `pnpm --filter @openmind/api-client generate`; sqlc v1.29.0 regen — schema changes). Never hand-edit generated files.
- All queries user-scoped except claim-by-code (scoped by hash). Errors `%w`; no banner comments; table-driven tests on real Postgres.
- **Toolchain:** prefix all Go commands `env -u GOROOT /opt/homebrew/bin/go` from `apps/api` (broken goenv shim; ignore stale gopls diagnostics). Test DB: `docker compose up -d db` → localhost:5433, db `openmind_test` (create if missing); suites `-p 1`.
- openapi.yaml style: inline params/responses (mirror `/items/{id}` / `/feeds`).

### Task 1: Schema + queries + `internal/auth` core (keys, codes, hashing) + unit tests

**Files:**
- Create: `apps/api/internal/store/migrations/0011_auth.sql`, `apps/api/internal/store/queries/auth.sql`, `apps/api/internal/auth/keys.go`, `apps/api/internal/auth/keys_test.go`
- Generated: `internal/store/db/*` (sqlc regen)

**Interfaces (later tasks consume):**
- `auth.GenerateKey() (full string, hash []byte, prefix string, err error)` — `full = "omk_" + base64.RawURLEncoding(32 random bytes)` (47 chars total), `hash = sha256(full)`, `prefix = full[4:12]`.
- `auth.HashKey(full string) []byte` — sha256.
- `auth.GenerateCode() (code string, hash []byte, err error)` — 8 chars Crockford-base32 (alphabet `0123456789ABCDEFGHJKMNPQRSTVWXYZ` minus `0,1,O,I` → use `23456789ABCDEFGHJKMNPQRSTVWXYZ`, crypto/rand), displayed as `ABCD-EFGH`; hash of the **undashed uppercase** form. `auth.NormalizeCode(s string) string` (strip dashes/spaces, uppercase).
- sqlc queries: `CreateAPIKey`, `ListAPIKeys` (user-scoped, revoked excluded or flagged — include with revoked_at for display), `RevokeAPIKey` (user-scoped, :execrows), `GetAPIKeyByHash` (join users; only unrevoked), `TouchAPIKeyLastUsed`, `CreateDeviceLink`, `ClaimDeviceLink` (single UPDATE … WHERE code_hash=$1 AND claimed_at IS NULL AND expires_at > now() RETURNING user_id — atomic single-use), `GetUserByClerkID`, `CreateUserFromClerk`.

- [ ] **Step 1: migration `0011_auth.sql`:**
```sql
ALTER TABLE users ADD COLUMN clerk_user_id text UNIQUE;
ALTER TABLE users ADD COLUMN email text NOT NULL DEFAULT '';

CREATE TABLE api_keys (
    id           uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id      uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    name         text NOT NULL,
    key_hash     bytea NOT NULL UNIQUE,
    prefix       text NOT NULL,
    created_at   timestamptz NOT NULL DEFAULT now(),
    last_used_at timestamptz,

);
CREATE INDEX api_keys_user_idx ON api_keys (user_id, created_at DESC);

CREATE TABLE device_links (
    code_hash   bytea PRIMARY KEY,
    user_id     uuid NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    device_hint text NOT NULL DEFAULT '',
    created_at  timestamptz NOT NULL DEFAULT now(),
    expires_at  timestamptz NOT NULL,
    claimed_at  timestamptz
);
```

### Task 2: JWT verification (`internal/auth/jwt.go`) + JWKS cache + tests

**Files:**
- Create: `apps/api/internal/auth/jwt.go`, `apps/api/internal/auth/jwt_test.go`
- Modify: `apps/api/go.mod` (add `github.com/golang-jwt/jwt/v5`)

**Interfaces:**
- `auth.NewJWTVerifier(issuer string) *JWTVerifier` — JWKS URL derived as `issuer + "/.well-known/jwks.json"`.
- `(*JWTVerifier).Verify(ctx, token string) (ClerkClaims, error)` — `ClerkClaims{Subject (clerk user id), Email string}`. Enforces: RS256 only (reject alg none/HS*), `iss` == issuer, `exp`/`nbf` with 30s leeway. `sub` required.
- JWKS cache: fetch once, cache keys by `kid`; on unknown kid, refetch at most once per 5 minutes (cooldown guards DoS-by-bad-kid); 10s HTTP timeout; thread-safe (mutex).

- [ ] **Step 1:** `go get github.com/golang-jwt/jwt/v5` (latest v5).
- [ ] **Step 2 (TDD):** `jwt_test.go` — generate an RSA keypair in-test; serve a fake JWKS (httptest) with the public key (`kid: "test1"`, `alg: RS256`, `use: sig`, n/e base64url); mint tokens with `golang-jwt` signing. Cases: valid → claims (sub, email from `email` claim if present); expired → error; wrong issuer → error; alg=HS256 signed with a secret → rejected; unknown kid → error (and only one refetch within cooldown — assert fetch count via handler counter); tampered signature → error.
- [ ] **Step 3:** implement. JWKS parse: fields `keys[] {kid, kty=RSA, n, e}` → `rsa.PublicKey` (base64url big.Int). Use `jwt.NewParser(jwt.WithValidMethods([]string{"RS256"}), jwt.WithIssuer(issuer), jwt.WithLeeway(30*time.Second), jwt.WithExpirationRequired())` and a keyfunc reading `kid` from the header into the cache.
- [ ] **Step 4:** green; commit `feat(auth): clerk jwt verification with jwks cache`.

**Files:**
- Modify: `apps/api/internal/api/auth.go` (middleware rework), `server.go` (NewServer signature: replace `token string` with an `AuthConfig`), `cmd/openmind/main.go` (env → AuthConfig), `internal/api/ratelimit.go` (claim bucket + guarded()), `openapi.yaml`

- Generated: `gen.go`, `packages/api-client/src/schema.d.ts`

**Interfaces:**
- `api.AuthConfig{Mode string /* "token"|"clerk" */; LegacyToken string; Verifier *auth.JWTVerifier}`; env: `AUTH_MODE` (default `token`), `CLERK_ISSUER` (required in clerk mode — fail fast at startup if missing).
- Middleware resolution (per spec): `omk_` prefix → key hash lookup → user (touch last_used ≤1/min; revoked → 401); else clerk mode → JWT verify → GetUserByClerkID / JIT `CreateUserFromClerk` → user; else token mode → constant-time legacy compare → dev user. Unauthed → 401. `/healthz` open; `POST /device-links/claim` bypasses auth but NOT its rate bucket.
- Contract (operationIds): `listApiKeys` GET `/api-keys` → 200 `[ApiKey{id,name,prefix,createdAt,lastUsedAt?,revokedAt?}]`; `createApiKey` POST `{name}` → 201 `ApiKeyCreated{key, id, name, prefix, createdAt}`; `revokeApiKey` DELETE `/api-keys/{id}` → 204/404; `createDeviceLink` POST `/device-links {deviceHint?}` → 201 `{code, expiresAt}`; `claimDeviceLink` POST `/device-links/claim {code, deviceName}` → 201 `{key, name}` / 404 uniform. Name limits: trim, 1..80 runes.
- Claim rate bucket: 5 req/min, burst 5, per-IP, distinct from the global limiter; both `/api-keys*` and `/device-links*` also in `guarded()`.
