# Drift (Resurfacing) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]` tracking.

**Goal:** Daily resurfacing of forgotten saves — GET /drift batch, keep (→pin) / let-go actions, full-screen /drift experience, live Drift nav. Spec: `docs/superpowers/specs/20260706-drift-design.md`.

**Architecture:** `items.last_drifted_at` column; read-only `GET /drift` (batch + total); `POST /drift/{id}{keep}` (mark drifted + optionally pin); web `/drift` full-screen flow; live sidebar Drift nav. Reuses Desk's pin plumbing.

## Global Constraints

- Candidate = `status='enriched' AND pinned_at IS NULL AND (last_drifted_at IS NULL OR last_drifted_at < now()-interval '30 days')`. Order `last_drifted_at NULLS FIRST, created_at ASC`. Batch 5.
- `GET /drift` is READ-ONLY (no mutation); `POST /drift/{id}{keep}` mutates. Every query user-scoped (cross-tenant → 404/excluded). Additive migration (no generated-column touch). No `Item` schema change (last_drifted_at internal).
- Generated code never hand-edited; errors `%w`; no banner comments. `go test -p 1 ./... && golangci-lint run ./...` + web `pnpm turbo run build lint --filter=web` green. Tokens-only web EXCEPT the intentional dark Drift canvas (documented). Commit per task.

**Interfaces:** migration adds `last_drifted_at timestamptz` (nullable, no default; optional partial index `(user_id) WHERE pinned_at IS NULL AND status='enriched'` — keep simple, a plain scan is fine at scale, skip the index or add a modest one). sqlc: `ListDriftCandidates(user_id, limit int32) :many` (the candidate WHERE + ORDER), `CountDriftCandidates(user_id) :one`, `DriftAction(user_id, id, keep bool) :execrows` (`UPDATE items SET last_drifted_at=now(), pinned_at = CASE WHEN $3 THEN now() ELSE pinned_at END, updated_at=now() WHERE user_id=$1 AND id=$2`). openapi: `DriftResponse{items: Item[], total: int}`; `GET /drift` → 200 DriftResponse; `POST /drift/{id}` req `{keep: bool}` → 200 (ok) / 404. Handlers: `GetDrift` → ListDriftCandidates(uid,5)+CountDriftCandidates → DriftResponse (items never null); `DriftItem` → decode {keep}, DriftAction (0 rows→404), 200.
