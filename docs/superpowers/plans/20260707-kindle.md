# Send to Kindle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Email a saved item — or a Lens's current matches as a digest — to a Kindle address as a generated EPUB, fully async via a River job.

**Architecture:** Two new stdlib-only packages: `internal/epub` (EPUB 3 zip writer) and `internal/mailer` (MIME + SMTP sender behind a `Mailer` interface). A `send_kindle` River job renders + sends in the worker; `POST /items/{id}/kindle` and `POST /lenses/{id}/kindle` enqueue and return 202 (404 unowned / 409 unconfigured / 422 nothing-to-send). Web gets two buttons + cookie proxies. SMTP config is optional env — unconfigured instances degrade to a clear 409.

**Tech Stack:** Go stdlib only (`archive/zip`, `html/template`, `mime/multipart`, `encoding/base64`, `net/smtp`, `crypto/tls`), existing River/sqlc/oapi-codegen, Next.js.

Spec: `docs/superpowers/specs/20260707-kindle-design.md`.

## Global Constraints

- **No new Go dependencies.** Both new packages are stdlib-only.
- Contract workflow: edit `openapi.yaml` → regenerate (oapi-codegen v2.4.1 + `pnpm --filter @openmind/api-client generate`) → implement. Never hand-edit generated files.
- Jobs: payload = IDs only; fetch fresh inside the job; safe to re-run (a re-run may send a duplicate email — acceptable, note in code).
- All queries user-scoped; 404 for cross-tenant/missing. Errors `%w`. No banner comments. The SMTP password must never be logged.
- **Toolchain:** all Go commands prefixed `env -u GOROOT /opt/homebrew/bin/go` from `apps/api` (broken goenv shim; ignore stale gopls diagnostics). Regen commands: `env -u GOROOT /opt/homebrew/bin/go run github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@v2.4.1 -config oapi.cfg.yaml ../../openapi.yaml`; sqlc unchanged this feature (no schema change!); `pnpm --filter @openmind/api-client generate` from root.
- **Test DB** for API tests: `docker compose up -d db`, `localhost:5433`/`openmind_test`, suites `-p 1`.
- openapi.yaml uses inline parameters/responses (no components refs) — mirror `/items/{id}` and `/lenses/{id}` blocks' style.

- [ ] **Step 3 (TDD): mailer tests first.** In-process fake SMTP server:

```go
// fakeSMTP listens on 127.0.0.1:0 and speaks just enough SMTP to accept one
// message, capturing the DATA payload for assertions.
func fakeSMTP(t *testing.T) (addr string, data *bytes.Buffer) {
	t.Helper()
	ln, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil { t.Fatal(err) }
	t.Cleanup(func() { _ = ln.Close() })
	buf := &bytes.Buffer{}
	go func() {
		conn, err := ln.Accept()
		if err != nil { return }
		defer conn.Close()
		r := bufio.NewReader(conn)
		fmt.Fprintf(conn, "220 fake ESMTP\r\n")
		inData := false
		for {
			line, err := r.ReadString('\n')
			if err != nil { return }
			if inData {
				if strings.TrimRight(line, "\r\n") == "." {
					inData = false
					fmt.Fprintf(conn, "250 ok\r\n")
					continue
				}
				buf.WriteString(line)
				continue
			}
			switch {
			case strings.HasPrefix(line, "EHLO"), strings.HasPrefix(line, "HELO"):
				fmt.Fprintf(conn, "250-fake\r\n250 8BITMIME\r\n") // no STARTTLS advertised
			case strings.HasPrefix(line, "MAIL"), strings.HasPrefix(line, "RCPT"):
				fmt.Fprintf(conn, "250 ok\r\n")
			case strings.HasPrefix(line, "DATA"):
				inData = true
				fmt.Fprintf(conn, "354 go\r\n")
			case strings.HasPrefix(line, "QUIT"):
				fmt.Fprintf(conn, "221 bye\r\n")
				return
			default:
				fmt.Fprintf(conn, "250 ok\r\n")
			}
		}
	}()
	return ln.Addr().String(), buf
}
```
Tests: Send a message with a small attachment → captured DATA contains `To:`, `Subject:`, `multipart/mixed` with a boundary, a `text/plain` part, and an attachment part whose base64 payload decodes byte-identical to the input; filename in `Content-Disposition`. No-auth path (Username empty) sends without AUTH.
- [ ] **Step 4: implement `mailer.New`.** Parse host/port from cfg; port 465 → `tls.Dial` then `smtp.NewClient`; otherwise `smtp.Dial`, then `client.StartTLS(&tls.Config{ServerName: host})` **only if** `client.Extension("STARTTLS")` is true; `smtp.PlainAuth` only when Username != "". Build the message with `mime/multipart`: headers (From/To/Subject/MIME-Version/Content-Type multipart/mixed), text part, attachment part base64-encoded in 76-char lines (`base64.StdEncoding` + manual wrapping or `mime/quotedprintable`-style writer — wrap at 76). CRLF line endings throughout. Respect ctx via a dial timeout (`net.Dialer{Timeout: 15s}.DialContext`).
- [ ] **Step 5: run.** `env -u GOROOT /opt/homebrew/bin/go test ./internal/epub/... ./internal/mailer/...` green; `go vet ./...` clean.
